# Describe Health and Sleep Quality Data

> Udacity — Statistics for Data Analysis Nanodegree, Course 2: Descriptive Statistics

## Overview

Descriptive statistics analysis of the Sleep Health and Lifestyle Dataset (373 records, 13 columns) covering physical activity, daily steps, heart rate, and sleep quality metrics.

## Key Findings

| Section | Metric | Result |
|---------|--------|--------|
| Measures of Center | Physical Activity Mean | 59.17 min |
| Measures of Center | Physical Activity Median | 60.0 min |
| Measures of Spread | Daily Steps Std Dev | 1,617.92 |
| Measures of Spread | Daily Steps IQR | 2,400 |
| Shape & Outliers | Heart Rate Outliers | 7 values (80-86 bpm) |

## Analysis Sections

1. **Physical Activity** — Mean, median, mode analysis
2. **Daily Steps** — Standard deviation, range, IQR, five-number summary
3. **Heart Rate** — Distribution shape, outlier detection via IQR method
4. **Sleep Quality** — Cross-variable analysis with occupation and BMI

## Dataset

[Sleep Health and Lifestyle Dataset](https://www.kaggle.com/datasets/uom190346a/sleep-health-and-lifestyle-dataset) — 373 records × 13 columns

## Tech Stack

Python 3, pandas, NumPy, python-pptx
